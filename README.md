# bretflix-logos

Channel logos for Bretflix live TV (ErsatzTV channels watched through Plex Live TV).

They live here, publicly, because Plex refuses to fetch guide images from LAN addresses, so
ErsatzTV's own logo URLs never load in the Plex guide. Each ErsatzTV channel's logo points at
`https://raw.githubusercontent.com/brettsallee/bretflix-logos/main/channels/<slug>.png`.

Generated by `~/docker/ersatztv/.claude/scripts/make_logo.py` (Vulf Mono Bold Italic):

    uv run --script make_logo.py channels dundertv sitcoms shonen "cozy anime"
    uv run --script make_logo.py .        # bretflix-white.png / bretflix-black.png
